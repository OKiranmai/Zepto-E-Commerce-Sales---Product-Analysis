# Zepto-E-Commerce-Sales-&-Product-Analysis

## 📌 Project Overview

This project focuses on cleaning, exploring, and analyzing a **Zepto e-commerce product dataset** sourced from **Kaggle in CSV format**. The dataset contains information about products, categories, pricing, discounts, stock availability, and product quantities.

The CSV dataset was imported into **MySQL Workbench**, where SQL was used to clean the data, perform exploratory analysis, identify patterns, and generate meaningful insights from the product data.

## 🎯 Objectives

* Clean and prepare the raw e-commerce dataset for analysis.
* Explore the structure and characteristics of the dataset.
* Analyze product categories and product availability.
* Compare **MRP, selling prices, and discount percentages**.
* Identify products with high and low discounts.
* Analyze in-stock and out-of-stock products.
* Identify duplicate products and frequently occurring products.
* Analyze product weights and pricing patterns.
* Use SQL queries to answer business-related questions from the dataset.

## 🛠️ Tools & Technologies

* **MySQL**
* **MySQL Workbench**
* **SQL**
* **CSV Dataset**
* **Kaggle**

## 🔍 Key Analysis Performed

The project includes data cleaning and exploratory SQL queries using concepts such as:

* `SELECT` and `WHERE`
* `ORDER BY`
* `GROUP BY`
* `HAVING`
* `COUNT()`
* `AVG()`
* `MIN()` and `MAX()`
* `DISTINCT`
* Aggregate functions
* Filtering and sorting
* Conditional analysis
* Duplicate record identification

The analysis was used to investigate product pricing, discounts, availability, stock status, quantities, categories, and other characteristics of the Zepto product catalog.

## 📊 Project Workflow

**Kaggle CSV Dataset → Data Import → Data Cleaning → Data Exploration → SQL Analysis → Business Insights**

This project helped me strengthen my practical understanding of **SQL, data cleaning, exploratory data analysis, aggregation, filtering, and extracting insights from real-world datasets**.
